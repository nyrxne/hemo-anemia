H.E.M.A. — Hematological Evaluation of Machine-learning Accuracy AI for Healthcare Accessibility

Does anemia-screening AI still work once it leaves the lab it was trained in?

Smartphone photos of the eye's conjunctiva can screen for anemia without a needle. Published models look accurate — but almost all of them are validated on the same population and clinic they were trained on. This project tests what happens when that assumption is removed.

The question

A model that works in one clinic isn't the same as a model that works.

Non-invasive screening only matters if it holds up outside the exact conditions it was built in.

RISK 01

Narrow validation

Many published anemia-screening models report strong accuracy — but on data from a handful of cameras, lighting setups, and patient populations. That's not evidence the model generalizes; it's evidence it fits that setting.

RISK 02

Silent failure

A screening tool that quietly loses accuracy in a new clinic doesn't announce it. It just gives a health worker a wrong answer with the same confidence as a right one.

The dataset & the audit

Train on some facilities. Test on ones the model has never seen.

CP-AnemiC contains conjunctival images and matched clinical hemoglobin readings from ten healthcare facilities in Ghana. Instead of the usual random train/test split, we hold out entire facilities — a stricter test of whether the model learned anemia, or learned one clinic's cameras and patients.

Cleaning the dataset before touching the model

Before any training happened, the dataset itself had to be audited. CP-AnemiC started at 710 images. We found 212 exact duplicate copies using MD5 hashing, and 14 additional near-duplicates using perceptual hashing. We also excluded records with cross-hospital identity conflicts or conflicting hemoglobin labels, to reduce the risk of leakage between splits. What was left: 401 clean, site-reliable images — 173 anemic, 228 non-anemic — across 10 hospitals in Ghana.

710 → 401

If the same photograph leaks into both training and testing, a model can look accurate simply because it has effectively already seen the answer. This step is what makes the cross-site numbers in the next section trustworthy.

The method

Where a model belongs, and where it doesn't.

Fixed pipeline

Conjunctiva detection & crop

Locating and cropping the conjunctival region from a raw eye photo is a well-defined image-processing step — no learning required to get consistent, comparable input images.

Fine-tuned CNN

Hemoglobin / anemia estimation

A pretrained EfficientNet or MobileNet backbone, fine-tuned on CP-AnemiC, maps conjunctiva images to an anemia classification (and, where the data supports it, an estimated hemoglobin value).

Fixed thresholds

Clinical cutoffs

Converting a continuous estimate into "screen positive / negative" uses the same WHO hemoglobin thresholds a clinician would — not a learned decision boundary.

Cross-site audit

Per-facility error analysis

Sensitivity, specificity, AUROC and calibration are computed per held-out facility, then checked against differences in camera, lighting, and patient demographics to see what actually drives any drop.

The reveal

The gap between "it works" and "it works here too" — measured.

This isn't a projection anymore. This is what happened when the trained model was pointed at Ahmadiyya Muslim Hospital — a facility it never saw during training or validation — compared to how it performed on held-out data from the hospitals it did train on.

AUROC0.7830.540
Accuracy65.3%52.1%
Sensitivity68.2%46.4%
Specificity63.0%55.6%

AUROC: 0.783 → 0.540

— a drop of 0.243

0.783 reflects a moderately useful screening signal on data from the hospitals the model trained on. 0.540 is close to the 0.5 line associated with random ranking. On this single run, the model's apparent performance did not transfer to the unseen hospital.

The model had learned something — the open question is whether it had learned anemia, or partly learned the environment the images were collected in. That's an association worth investigating, not a proven cause.

These numbers are from one run, seed 42, on one held-out hospital. A three-seed robustness check (seeds 42, 123, 7) is in progress to see how much of this gap holds up once the train/validation shuffle changes. Results pending.

Why might this be happening?

Age was similar between groups (32.4 vs. 30.3 months) and class balance was only modestly different (44.2% vs. 38.4% anemic) — neither looks like an obvious explanation. Severity distribution did differ: the training pool had proportionally more severe cases (13 severe / 84 moderate / 48 mild) than Ahmadiyya (4 / 15 / 9). Severe anemia tends to produce more visually obvious conjunctival pallor, so this is a plausible contributing factor — not a confirmed cause. Camera, lighting, and background differences between sites haven't been quantitatively measured yet.

Beyond accuracy

An accurate result nobody can read isn't accessible.

A screening system built for under-resourced clinics has to reach the health worker in the language they actually work in. We route screening result text through gTTPS, the project's chosen translation and speech-output layer, so a result can actually be understood in the language the health worker or patient uses.

gTTPS doesn't make the anemia model more accurate — it makes the information the model already produces easier to understand. Accuracy first, accessibility alongside it, never as a substitute.

Where this could be wrong

What the results above don't yet tell us.

  • Both the validation and held-out test sets are small — a single run's numbers can shift meaningfully with a different data split.
  • CP-AnemiC has no patient identifiers, so patient-level independence between splits isn't fully verifiable — some apparent leakage risk can't be ruled out beyond the duplicate/near-duplicate audit already done.
  • Only one hospital (Ahmadiyya) has been used as a held-out site so far — this is one data point on generalization, not a general finding across sites.
  • Acquisition factors — camera model, lighting, background — haven't been quantitatively measured, so their contribution to the observed drop is inferred, not confirmed.

Not another anemia classifier — an audit of whether one can be trusted.

The goal isn't a higher accuracy number. It's knowing where the number stops being true.
