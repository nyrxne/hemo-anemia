H.E.M.A. — Hematological Evaluation of Machine-learning Accuracy AI for Healthcare Accessibility

Does anemia-screening AI still work once it leaves the lab it was trained in?

Smartphone photos of the eye's conjunctiva can screen for anemia without a needle. Published models look accurate — but almost all of them are validated on the same population and clinic they were trained on. This project tests what happens when that assumption is removed.

The question

A model that works in one clinic isn't the same as a model that works.

Non-invasive screening only matters if it holds up outside the exact conditions it was built in.

RISK 01

Narrow validation

Many published anemia-screening models report strong accuracy — but on data from a handful of cameras, lighting setups, and patient populations. That's not evidence the model generalizes; it's evidence it fits that setting.

RISK 02

Silent failure

A screening tool that quietly loses accuracy in a new clinic doesn't announce it. It just gives a health worker a wrong answer with the same confidence as a right one.

The dataset & the audit

Train on some facilities. Test on ones the model has never seen.

CP-AnemiC contains conjunctival images and matched clinical hemoglobin readings from ten healthcare facilities in Ghana. Instead of the usual random train/test split, we hold out entire facilities — a stricter test of whether the model learned anemia, or learned one clinic's cameras and patients.

The method

Where a model belongs, and where it doesn't.

Fixed pipeline

Conjunctiva detection & crop

Locating and cropping the conjunctival region from a raw eye photo is a well-defined image-processing step — no learning required to get consistent, comparable input images.

Fine-tuned CNN

Hemoglobin / anemia estimation

A pretrained EfficientNet or MobileNet backbone, fine-tuned on CP-AnemiC, maps conjunctiva images to an anemia classification (and, where the data supports it, an estimated hemoglobin value).

Fixed thresholds

Clinical cutoffs

Converting a continuous estimate into "screen positive / negative" uses the same WHO hemoglobin thresholds a clinician would — not a learned decision boundary.

Cross-site audit

Per-facility error analysis

Sensitivity, specificity, AUROC and calibration are computed per held-out facility, then checked against differences in camera, lighting, and patient demographics to see what actually drives any drop.

Beyond accuracy

An accurate result nobody can read isn't accessible.

A screening system built for under-resourced clinics has to reach the health worker in the language they actually work in. We plan to route result text through Bhashini, India's public multilingual AI platform, for translation and speech output.
